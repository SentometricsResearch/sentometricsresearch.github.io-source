# Archive

`papers_overview.csv` is the field-wide bibliography that used to drive the
`/publication/` section — 231 references, last updated in 2020.

It was retired in August 2026 when the hub was refocused on the team's own
output: an exhaustive bibliography has to be complete and current to be useful,
and search engines do exhaustiveness better than any hand-maintained list. The
file is kept here so the old list remains recoverable, and because the canonical
references it contains are worth mining if we ever want a reading list again.

It is not part of the build.
