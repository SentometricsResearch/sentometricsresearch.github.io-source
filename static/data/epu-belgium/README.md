# Economic Policy Uncertainty Index for Flanders, Wallonia and Belgium

## Cite as

Algaba, A., Borms, S., Boudt, K., Van Pelt, J. (2020). The economic policy uncertainty index for Flanders, Wallonia and Belgium. *Bank- en Financiewezen*, 2020/6. doi:10.2139/ssrn.3580000

## Coverage

Daily, 3 January 2000 to 22 June 2022. **The series is not currently maintained.**

## Columns

- `date` — ISO 8601
- `EPU Belgium (daily)` — raw daily index
- `EPU Belgium (smoothed)` — 30-day moving average
- `EPU Belgium Dutch (daily)` — Dutch-language sources, raw
- `EPU Belgium Dutch (smoothed)` — Dutch-language sources, smoothed
- `EPU Belgium French (daily)` — French-language sources, raw — no smoothed counterpart exists in the source file

## Differences from the deposited original

The original is semicolon-separated with a comma as decimal mark, which trips up
most default CSV readers. This copy is a standard comma-separated file with a
decimal point. Values are unchanged. The unnamed row-number column and the `Note`
column have been removed.
