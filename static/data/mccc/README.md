# Media Climate Change Concerns Index (MCCC)

## Cite as

Ardia, D., Bluteau, K., Boudt, K., Inghelbrecht, K. (2023). Climate change concerns and the performance of green versus brown stocks. *Management Science*, 69(12), 7607–7632. doi:10.1287/mnsc.2022.4636

## Coverage

Daily and monthly, 1 January 2003 to 30 June 2025, in five vintages — one file each.

The methodological break sits between the `ms-2022` and `2023-update` vintages: the
Houston Chronicle was dropped, some sources came from alternative aggregators, and
LIWC2022 replaced LIWC2015. Correlations with the previous vintage exceed 0.95 on the
overlapping year. Cite the vintage you actually used.

## Columns

- `Date` — ISO 8601
- `Aggregate` — headline concern index
- `cluster_*` — four thematic subindices
- `<topic>` — 30 topical subindices

## Differences from the deposited original

One file per vintage and frequency instead of a ten-sheet workbook, so each vintage
can be cited on its own. The six citation and licence rows that preceded the header
of every sheet appear once, above.
