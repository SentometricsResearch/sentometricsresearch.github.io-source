{{/* Display author list. Project override of the theme partial. The upstream version emits whenever a profile page exists, which produced for our team members: their profiles are data only (`_build.render: false`), so the permalink is empty and the name became a link that reloaded the page. Here the link target is, in order: the person's own website when their profile sets one, then the rendered profile/taxonomy page, then no link at all. A team member's name therefore points at their own site — the same target as in the Team section — and co-authors without a profile keep linking to their list of papers on this site. */}} {{- $taxonomy := "authors" }} {{ with .Param $taxonomy }} {{ $link_authors := site.Params.link_authors | default true }} {{ range $index, $value := . }} {{- $profile_page := site.GetPage (printf "/%s/%s" $taxonomy (. | urlize)) -}} {{- $name := $profile_page.Params.name | default ($value|markdownify) -}} {{- $href := "" -}} {{- $external := false -}} {{- with $profile_page -}} {{- with .Params.website -}} {{- $href = . -}} {{- $external = true -}} {{- else -}} {{- $href = .RelPermalink -}} {{- end -}} {{- end -}} {{- if gt $index 0 }}, {{ end -}} {{- if and $href $link_authors -}} {{ $name }} {{- else -}} {{ $name }} {{- end -}} {{- end -}} {{- end -}}
